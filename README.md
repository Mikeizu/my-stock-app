# my-stock-app
stock search app

## Download the app

[Download MIKEIZU Stock Intelligence PRO v2.zip](https://github.com/Mikeizu/my-stock-app/raw/refs/heads/main/downloads/MIKEIZU_Stock_Intelligence_PRO_v2.zip)

Extract the ZIP into a writable folder. On Windows, install Python 3.11–3.13 and double-click `START_WINDOWS.bat` inside the extracted app folder. On macOS/Linux, run `bash run_linux_mac.sh` from that folder. Internet is required to install dependencies and retrieve market data/news.

## Included

- Dropdown for 30 listing markets, with company and ticker discovery.
- Combined seven-factor percentage research rankings, data coverage and source timestamps.
- Linked news, conditional prospects and risks, dividend planning, scenarios and backtests.
- Licensed CSV history imports, including the Nigeria/NGX workflow.

The percentage score summarizes research evidence; it is not a profit probability or a predicted return. Country presets and news searches are not exhaustive. Nigeria requires authorized CSV histories; no live NGX feed is bundled.

Source code, tests, setup instructions and methodology are in [MIKEIZU_Stock_Intelligence_PRO](MIKEIZU_Stock_Intelligence_PRO/README.md).

Validation: 65 automated tests passed, and real-browser dashboard checks passed. Live Yahoo/Google feed validation was blocked by the development cloud's network policy; no live recommendation was verified. Access on your computer depends on your network and the providers.
